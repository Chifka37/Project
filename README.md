## Описание программы

**Task Manager System** — это консольное приложение для управления личными и рабочими задачами, разработанное в рамках итоговой аттестации по курсу Python.

**Что делает программа:**
- Создаёт, просматривает, обновляет и удаляет задачи (CRUD)
- Фильтрует задачи по приоритету (low/medium/high), статусу (pending/in_progress/completed) и заголовку
- Обрабатывает отложенные задачи в режиме очереди (FIFO)
- Позволяет отменить последнюю операцию через стек (LIFO)
- Автоматически сохраняет все задачи в JSON файл
- Проверяет корректность всех вводимых данных
- Показывает статистику по всем задачам

**Зачем нужна:**
Программа помогает организовать рабочее время, отслеживать дедлайны, управлять приоритетами и не забывать о важных задачах. Подходит для индивидуального использования и демонстрации профессиональных навыков разработки.
